<h1>Как использовать фреймворк Aluzin:<h1></h1>
  1. Создайте проект в RustRover или VS Code<br>
  2. Распакуйте Aluzin.zip в проект<br>
  3. Когда вы написали код в template.alzn введите следующую команду в терминале: rustc server.rs<br>
  4. Если выскакивает Connection Aborted то просто обновите страницу. Это нормально.
